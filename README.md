A chess engine in under 4 KB of Python: negamax alpha-beta search with a transposition table, quiescence search, null-move pruning, PVS/LMR and piece-square-table evaluation, running on a fixed 70,000-node-per-move budget — fully deterministic, no wall clock. On the kit's sealed practice gauntlet it scored Elo 1,364 / 1,279 / 1,191 across the three instances (mean 1,278).

## Run it

```sh
MAKEFUN_ENV_URL=http://store:8080 python3 main.py
```
